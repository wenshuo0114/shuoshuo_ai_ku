# 小车在家

给自己儿子的本地陪伴页。Q 版小汽车。父母在旁边。不是网课，不是灰产，不做公开分发。Preview（预览）不当发布。

## 这一刀有什么

- 一页。点小车，回一句短话。能停。
- 兴趣选一样：开车、假装玩、听故事、跑跳。顺着聊几轮。
- 没钥匙也能玩：本地短句。
- 填了钥匙、并且开着本地小服务：才调用上游。失败用短句兜底。
- 不保存对话。不采集。不落盘。关页即没。
- 不注册。不要姓名住址学校电话。不上传录音照片。

## 怎么打开

不填钥匙：

```bash
python3 serve.py
```

浏览器打开 `http://127.0.0.1:8765/` 。直接打开 `index.html` 也能玩，只用本地短句。

要上游：家长自己去 [DeepSeek 开放平台](https://platform.deepseek.com/) 申请 API Key（接口钥匙）。我们不代申请、不保管、不写进仓库、不写进聊天。钥匙只放家长自己的密码库。页面上那一个密码框，用时系统锁自动填，刷新就没。

## 硬限制（不做）

- 语音：不做。
- 精细 3D（三维）：不做。车上那一点透视是卡通壳。
- 家长后台：不做。
- 任务卡、颜色数字动物清单硬教：不做。
- 支付、收费、会员、孩子账号：不做。
- 换别家上游：不做。这一刀只转 DeepSeek Chat（深度求索对话）。
- 浏览器直连上游：不做。会被跨域拦住；打开文件时即使填了钥匙也不外发。
- 自建保险柜 / localStorage（本地存储）存钥匙：不做。

## 安全

不聊成人、恐吓、自伤。不外链乱跳。跑题回到车上。不要求「不要告诉大人」。玩一会儿会给家长一个【弹窗】：该休息了。

# 小车在家

给自己儿子的本地陪伴页。Q 版小汽车。父母在旁边。只在家里本机玩。不接 API。不上公网。

## 有什么

- 一页。点小车，回一句短话。能停。
- 兴趣选一样：开车、假装玩、听故事、跑跳。顺着聊几轮。
- 只用本地短句。不保存对话。关页即没。
- 不注册。不要姓名住址学校电话。不上传录音照片。

## 出厂后怎么放、怎么玩

1. 从 git 拉到一个**新文件夹**（不要放在用户目录根上）。
2. 3D 模型若还要，另下进这个文件夹。不要把 WSL、Caddy、证书拷进来。
3. 打开：

```bash
python3 serve.py
```

浏览器只开 `http://127.0.0.1:8765/` 。也可以直接打开 `index.html`。

不要填钥匙、不要 Caddy、不要 VPS、不要 Hyper-V 共享盘。

荣耀本机出厂进桌面后，若要关掉 Hyper-V / WSL：右键 `disable-hyperv-on-this-pc.bat` → 以管理员身份运行，然后重启。脚本开头也写了安全芯片、跳过 Wi-Fi 那两步（只能你在笔记本上点）。

## 硬限制（不做）

- API、上游模型、公网发布：不做。
- 语音：不做。
- 精细 3D：不做。车上那一点透视是卡通壳。
- 家长后台：不做。
- 支付、收费、会员、孩子账号：不做。

## 安全

不聊成人、恐吓、自伤。不外链乱跳。跑题回到车上。不要求「不要告诉大人」。玩一会儿会给家长一个【弹窗】：该休息了。

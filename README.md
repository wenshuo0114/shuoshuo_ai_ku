# 小车陪玩

给家里 3 到 4 岁孩子的**本地**陪伴页。父母在旁边。只要自己家用。

不是豆包缩小版，不是网课，不是公开产品。Preview（预览）不当发布。

## 有什么

- 一页。Q 版小汽车。点一下回一句短话。
- 兴趣选一样：车、假装玩、故事、跑跳。顺着聊几轮。
- 没填钥匙也能玩（本地短句）。
- 填了钥匙，本机才转去上游一次请求。失败仍用短句。
- 关页即没。不注册、不存对话、不采集。

## 没有什么

- 没有语音、没有精细 3D、没有家长后台、没有任务卡。未做。
- 没有支付、收费、会员。
- 不申请、不代管、不保管 API Key（钥匙）。不写进仓库、不写进聊天。
- 不要孩子姓名、住址、学校、电话。不上传录音照片。

## 本机打开

```bash
python3 play.py
```

浏览器打开它打印的地址（只听 `127.0.0.1`）。不要把这一页挂到公网。

直接打开 `index.html` 也能点着玩。没有本机服务时，上游调用会失败，仍用本地短句。

## 钥匙（可选）

家长自己去 DeepSeek（深度求索）上游申请。我们不代申请。

钥匙只放进家长自己的密码库。页面上那个密码框，用时系统锁可自动填。刷新就没。

不要把钥匙发到 Issue、Pull Request（拉取请求）或聊天里。

## 检查

```bash
python3 test_page.py
```
